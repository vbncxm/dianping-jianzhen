# 滇评鉴真 · 智能评论净化系统

> 以昆明酒店 OTA 评论为样本，融合文本语义、图文一致与群体行为三层特征，构建「技术清洗 — 动态量化 — 实地验证」闭环，输出评论可信度评分与分区酒店性价比榜单。
>
> 云南大学大学生创新训练项目资助（校级，项目编号：20257073）

---

## 一、项目组成

仓库包含三部分，可独立运行也可一体启动：

| 部分 | 内容 | 入口 |
| --- | --- | --- |
| **春城金鉴榜**（前端） | 5 区性价比榜单总榜、25 家单店详情页、结项答辩演示站 | `榜单生成/output/index.html`<br>`榜单生成/output/showcase.html` |
| **滇评鉴真**（后端） | 评论清洗引擎、酒店评分重算、REST 接口、静态站点托管 | `python -m backend.serve` |
| **数据处理流程** | 分区归属、评分排序、评论采集、相册采集、页面生成 | `榜单生成/*.py` |

前端页面为自包含单文件（图片 base64 内嵌、ECharts 本地内联），双击即可打开，无需服务器。

## 三、快速开始

### 1. 环境

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 启动后端（含前端托管）

```bash
cd 榜单生成
python -m backend.serve               # http://127.0.0.1:8000
```

| 地址 | 说明 |
| --- | --- |
| `http://127.0.0.1:8000/` | 春城金鉴榜总榜 |
| `http://127.0.0.1:8000/demo` | 结项答辩演示站 |
| `http://127.0.0.1:8000/docs` | 接口文档 |

### 3. 只看页面

直接双击 `榜单生成/output/showcase.html` 或 `index.html`。

### 4. 重跑清洗流水线

```bash
cd 榜单生成
python -m backend.run
```

## 五、方法要点

### 1. 三层特征融合

| 层 | 权重 | 模型 | 信号 |
| --- | --- | --- | --- |
| 文本语义 | 0.40 | BERT-BiLSTM | 营销夸张词、模板化雷同、极短无信息、套话齐夸、标点堆砌 |
| 图文一致 | 0.30 | CLIP + YOLOv8 | 声称实拍无图、多图配空洞正文、图文实体不对齐 |
| 群体行为 | 0.30 | GNN 异构图 | 短时爆发聚集、深夜发布、跨店刷评、异地活跃 |

融合采用模糊或累积而非加权平均，单条强证据即可抬升风险分：

```
Risk = 1 − ∏ (1 − sᵢ · gᵢ)
```

输出 0–100 可信度评分与 **12 类异常标签**归因，按三档处置：

- 高风险（≥60）：整条剔除
- 观察区（35–60）：线性降权，最多削 70%
- 低风险：正常参与评分

### 2. 动态性价比模型

```
性价比 = (评论质量 × 情感得分 × 设施得分) × 时间衰减 × 价格弹性 ÷ 价格
```

- 时间衰减 `e^(−λΔt)`，λ = 0.001，约 693 天后权重减半
- 价格弹性 `clamp((P / P̄)^0.30, 0.70, 1.40)`
- 设施得分由 AHP 权重合成
- 评论数不足时按贝叶斯收缩（C = 30）向全站先验收敛
